TRABAJO PRÁCTICO INTEGRADOR FINAL - Simulador de Misiones ARTEMIS (en C)

Universidad Tecnológica Nacional - Facultad Regional Resistencia (UTN- FRRe)
Grupo: 28
Comisión: K.1.2
Integrantes: Alvarez Albelda, Sofia Valentina - Araujo Ramos, Joaquin - Salladarre, Milagros 

Descripción del proyecto: 
 El presente proyecto consiste en el desarrollo de un simulador interactivo de lanzamiento del cohete Space Launch System (SLS), correspondiente a la misión Artemis.
 El programa está desarrollado en lenguaje C y permite representar las distintas etapas de un lanzamiento mediante cálculos y parámetros definidos para la simulación.
 El objetivo es aplicar los conocimientos adquiridos en la materia Algoritmos y Estructuras de Datos, incluyendo estructuras de control, modularización, funciones, validación de datos y procesamiento de información.
